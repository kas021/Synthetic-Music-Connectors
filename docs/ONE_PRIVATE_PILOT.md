# ONE owner pilot

This separate test catalogue contains ONE source only. The repository's normal
catalogue and all existing packages are unchanged. This is not an official
source promotion or an app store release.

Import `one-pilot-catalogue.json`, or the exact package
`packages/Synthetiq-ONE-Music-0.1.0.zip`. Identity3040 follows the existing
3006/3010/3030/3031 numbering; family `synthetiq_one_music` remains stable.

Requires the matching Synthetiq Music native-auth iPhone test build, explicit
user installation and the preapproved owner account/device. Public download
does not grant server access. Never put cookies, account tokens, media grants,
audio files or resolved stream URLs in this repository.

The pilot offers stored search/playback only, not upstream fetching, albums,
recommendations, offline downloads or export. Missing recordings fail honestly.
Real enrollment, renewal and audible phone playback require separate evidence.

Rollback: revert only this pilot-publication commit. Keep older sources and
packages unchanged; disable the pilot source in the app if needed. Do not erase
server security state, audio or user libraries.
